# Flink JARs

These JARs are not versioned (too large for GitHub).
Download them with:

```bash
make download-flink-jars
```

Or manually:
- flink-connector-kafka-3.1.0-1.18.jar
- iceberg-flink-runtime-1.18-1.5.2.jar
- flink-shaded-hadoop-2-uber-2.8.3-10.0.jar
- bundle-2.20.18.jar
- kafka-clients-3.4.0.jar
- flink-s3-fs-hadoop-1.18.1.jar
